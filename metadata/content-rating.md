# Content Rating Guide - Lexingo AI

## App Store Content Rating Information

### Primary Category: Education
### Secondary Category: Reference

## Content Rating Questionnaire Answers

### Violence
- **Cartoon or Fantasy Violence:** None
- **Realistic Violence:** None
- **Sexual Content or Nudity:** None
- **Profanity or Crude Humor:** None

### User-Generated Content
- **Contains user-generated content:** YES
- **Users can communicate with others:** NO (only with AI)
- **Users can post content for others to see:** NO

### Web Content
- **Contains or can access the web:** NO
- **Contains links to social media:** NO

### Content Restrictions
- **Mature/Suggestive Themes:** None
- **Simulated Gambling:** None
- **Horror/Fear Themes:** None
- **Medical/Treatment Information:** None

### User Content Specifics
**Type of user content:**
- Text documents (PDFs)
- Personal reading materials
- Translation queries

**Content moderation:**
- Users responsible for their own content
- No sharing between users
- Content processed locally when possible

### Data Collection
- **Account registration required:** YES
- **Location data collected:** NO
- **Personal information collected:** Email only
- **Purchases available:** YES (subscriptions)

## Expected Rating: 4+ (Ages 4 and up)

### Reasoning:
- Educational content only
- No inappropriate material
- User content is private (not shared)
- Minimal data collection
- No communication between users

## Additional Notes for Apple Review:

1. **Content Safety:** Users can only upload their own documents for personal study
2. **AI Safety:** AI responses are educational and filtered for appropriateness
3. **Privacy:** No user content is shared publicly or used for training
4. **Age Appropriate:** Suitable for all ages learning languages

## Parental Guidance Information:

- App is designed for language learning
- Users can upload their own educational materials
- AI provides educational assistance only
- No social features or user interaction
- Subscription purchases require parental approval for minors
